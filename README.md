# 🏠 Machine Learning Benchmark: Прогнозирование цен на квартиры

![Сравнение моделей](benchmark_results.png)

## 📌 О проекте
Данный проект представляет собой **бенчмарк различных алгоритмов машинного обучения** для задачи прогнозирования стоимости квартир на основе их характеристик (площади и количества комнат). Основная цель — сравнение эффективности разных моделей и выбор оптимального решения для практического применения в риелторской деятельности.

## 📁 Структура проекта
```
проект по бенчмарку ии для риеторов/
├── Benchmark_models.ipynb          # Основной файл сравнения и анализа моделей
├── DecisionTree.ipynb              # Модель дерева решений
├── Linear_regression.ipynb         # Простая линейная регрессия
├── Logistic_Regression.ipynb       # Линейная регрессия с логистическим подходом
├── Regularized_linear_regression.ipynb  # Регуляризованные модели (Ridge, Lasso)
├── Support_vector_machine.ipynb    # Метод опорных векторов
└── houses.ipynb                    # Генератор синтетических данных
```

## 🚀 Инструкция по запуску

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

или по отдельности:
```bash
pip install pandas numpy scikit-learn matplotlib seaborn joblib catboost scipy
```

### 2. Первый запуск (генерация данных)
**❗ВАЖНО:** Сначала необходимо сгенерировать данные для обучения и тестирования:
1. Откройте файл `houses.ipynb`
2. Выполните все ячейки
3. В результате будет создан файл `house` с синтетическими данными

### 3. Обучение моделей
После генерации данных последовательно запустите следующие файлы:
1. `Linear_regression.ipynb`
2. `Regularized_linear_regression.ipynb` 
3. `DecisionTree.ipynb`
4. `Support_vector_machine.ipynb`
5. `Logistic_Regression.ipynb`

Каждый из этих файлов:
- Загрузит данные из файла `house`
- Обучит свою модель
- Сохранит обученную модель в файл с расширением `.joblib`
- Продемонстрирует работу с моделью

### 4. Запуск бенчмарка
После того как все модели обучены и сохранены:
1. Откройте файл `Benchmark_models.ipynb`
2. Выполните все ячейки

В результате вы получите:
- Таблицу сравнения всех моделей по метрикам:
  - MSE (Среднеквадратичная ошибка)
  - MAE (Средняя абсолютная ошибка)
  - R² (Коэффициент детерминации)
  - MAPE (Средняя абсолютная процентная ошибка)
- Визуализацию результатов в виде столбчатых диаграмм
- Интерактивную секцию для прогнозирования цены новой квартиры
- Секцию поиска похожих квартир в датасете

## 📊 Интерпретация результатов

- **MSE (Mean Squared Error)** — показывает среднеквадратичное отклонение прогноза от реальных значений. Чем ниже — тем лучше.
- **MAE (Mean Absolute Error)** — показывает среднее абсолютное отклонение прогноза. Более интерпретируем, чем MSE.
- **R² (R-squared)** — коэффициент детерминации. Показывает долю дисперсии зависимой переменной, объясняемую моделью. Идеальное значение — 1.0.
- **MAPE (Mean Absolute Percentage Error)** — средняя абсолютная процентная ошибка. Показывает точность прогноза в процентах.

**Оптимальная модель** — та, у которой:
- минимальные значения MSE и MAE
- максимальное значение R² (ближе к 1.0)
- минимальное значение MAPE (чем ниже процент ошибки — тем лучше)

## 💡 Особенности проекта

1. **Синтетические данные** — данные генерируются с помощью алгоритма, имитирующего реальные рыночные закономерности, что позволяет протестировать модели в контролируемых условиях.

2. **Сравнительный анализ** — возможность наглядно сравнить эффективность разных алгоритмов машинного обучения для конкретной задачи.

3. **Практическая применимость** — готовые модели могут быть использованы для быстрой оценки стоимости квартиры, что полезно риелторам и частным лицам.

4. **Поиск аналогов** — функция поиска похожих квартир помогает не только оценить стоимость, но и найти реальные аналоги на рынке.

5. **Готовые модели** — все обученные модели сохраняются и могут быть повторно использованы без необходимости повторного обучения.

## 📝 Технические детали

- Все модели сохраняются в формате `.joblib` для эффективной сериализации
- Синтетические данные генерируются с использованием линейной модели с добавлением шума
- Для поиска похожих квартир используется евклидово расстояние как между исходными признаками, так и между нормализованными данными
- Визуализация результатов выполнена с помощью библиотек matplotlib и seaborn
